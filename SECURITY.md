# Security Policy

## Reporting a Vulnerability

If you believe you have found a security vulnerability in a Savant Helm chart, please report it privately — **do not open a public GitHub issue**.

**Preferred channel:** open a [GitHub security advisory](https://github.com/savantlabs/helm-charts/security/advisories/new) on this repository. This lets maintainers triage in private and coordinate a fix before disclosure.

**Alternative:** email `security@savantlabs.io`.

Please include:

- The chart name and version affected
- A clear description of the issue and its impact
- Steps to reproduce, or a minimal proof-of-concept
- Your assessment of severity and any suggested mitigations

We will acknowledge your report within two business days and keep you informed as we investigate. Once a fix is available we will coordinate public disclosure with you.

## Scope

This policy covers the Helm charts published from this repository. Issues in upstream charts we depend on (e.g. Bitnami, Kubeflow) should be reported to those projects directly; we will work with upstream where appropriate.

Product-level vulnerabilities in the Savant platform itself are handled through Savant's main security process — please contact `security@savantlabs.io` for those.
